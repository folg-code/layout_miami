Opis projektu

Projekt został przygotowany na podstawie projektu graficznego stworzonego w Figma.
Na jego podstawie została zakodowana responsywna strona internetowa z wykorzystaniem:

HTML5
SCSS

Celem projektu było wierne odwzorowanie wyglądu interfejsu zgodnie z projektem UI oraz zachowanie przejrzystej i uporządkowanej struktury kodu.

Technologie
HTML5
SCSS (Sass)
Funkcjonalności
Responsywny layout
Semantyczna struktura HTML
Organizacja stylów przy pomocy SCSS
